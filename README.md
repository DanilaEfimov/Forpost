# ForpostSimulator

Симулятор оператора БПЛА Форпост-П в кабине БМП.

## Структура проекта

- \src/\ - исходный код
- \ssets/\ - ресурсы (текстуры, звуки, шейдеры)
- \configs/\ - конфиги (JSON)
- \docs/\ - документация

## Сборка

\\\ash
mkdir build && cd build
cmake ..
make
\\\

## Управление

- \R\ - переключение ручной/автоматический режим
- \Мышь\ - управление камерой дрона
- \Space\ - маркировка цели
- \1/2\ - переключение каналов (оптика/тепловизор)
